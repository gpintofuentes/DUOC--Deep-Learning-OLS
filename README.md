# Aprendizaje Profundo (Deep Learning)

## Descripción

Este repositorio contiene el material de apoyo (notebooks, datasets y scripts) utilizado para dictar las clases del curso de Aprendizaje Profundo. Su propósito es servir como referencia y guía práctica para los estudiantes durante el semestre.

## Uso permitido

✅ Puedes descargar cualquier archivo del repositorio para tu uso personal, práctica y estudio.
✅ Puedes ejecutar los notebooks localmente o en Google Colab para seguir los talleres de clase.
❌ No modifiques ni subas cambios directamente a este repositorio. Los materiales aquí publicados corresponden a la versión oficial del curso.

Si detectas un error o tienes una sugerencia de mejora, por favor repórtalo directamente al profesor en lugar de modificar los archivos.

## Contenido

El repositorio está organizado por semana o unidad temática. Cada carpeta contiene:

- Notebooks de Jupyter (.ipynb) con el desarrollo de los talleres.
- Datasets (.csv) utilizados en los ejercicios.
- Material de apoyo adicional cuando corresponda.

## Requisitos

- Python 3.x
- Jupyter Notebook o Google Colab
- Librerías principales: TensorFlow / PyTorch, NumPy, Pandas, Matplotlib (revisar requirements de cada notebook)
